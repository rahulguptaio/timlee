# Localization and right-to-left support

English (`en`) is the only shipped locale. The machinery for more is in place
and tested with two pseudo-locales.

## Catalogs

- Website copy lives in ARB files under `web/locales/en/*.arb`, one file per
  area (`common`, `auth`, `marketing`, `settings`, `components`, `errors`).
  Keys are `<area>.<section>.<name>`; every key has an `@key` entry with a
  `description` for translators.
- Messages use an ICU MessageFormat subset: `{name}` arguments, `plural` and
  `select`, and a small set of inline tags (`<b>`, `<code>`, `<link>`).
- Catalogs are embedded (`web/locales/embed.go`) and compiled by
  `internal/i18n` at startup; a broken message stops the process.
- Auth emails have their own catalog in `internal/authsvc/locales`.
- `internal/i18n/cldr/tables.go` is generated: `go generate ./internal/i18n/cldr`.

## Templates and Go

- Templates call `{{ t .L "key" "arg" value }}` for text and
  `{{ th .L "key" ... }}` for messages that contain inline tags.
- `{{ href .L "/path" }}` and `.L.SignInPath "/apps"` produce locale-aware links.
- Go code uses `l.T(key, args...)` on the request's `*i18n.Localizer`
  (`s.localizer(r)` or `p.L` on a page).
- Numbers, money and dates go through the localizer's formatters, never `fmt`.

## Routing (`cmd/timlee-web/locale.go`)

- The default locale is unprefixed; other locales are a path prefix: `/` and
  `/de/`, `/sign-in` and `/de/sign-in`.
- `appRoots` (`/apps`, `/settings`, `/sign-in/desktop`) and files (`/assets`,
  `/.well-known`, anything with an extension) keep one URL in every language
  and follow the reader: account preference, then the `timlee.locale` cookie,
  then English. Add a new app area to `appRoots` if its pages are personal.
- Nothing redirects on `Accept-Language`, address or cookie. A reader whose
  language differs is offered theirs in a dismissable banner.
- `POST /locale` stores the choice in the cookie and, when signed in, the account.

## Client strings

Components read a JSON block (`<script id="timlee-i18n">`) the server renders
from `componentClientKeys` in `cmd/timlee-web/client_i18n.go`. A test keeps
that list equal to the keys the TypeScript calls `t()` with.

## Right-to-left

Use logical CSS properties (`margin-inline-start`, `inset-inline-end`) and
`dir="auto"` / `<bdi>` around user text. The document's `dir` comes from the
locale.

## Testing

`TIMLEE_PSEUDO_LOCALES=true` adds `en-xa` (accented, longer) and `ar-xb`
(right-to-left). `cmd/timlee-web/locale_test.go` covers routing, the banner,
the switcher and sign-in flows in them.
